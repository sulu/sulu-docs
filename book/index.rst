The Book
========

When you work through this book, you will build a website based on Sulu from scratch. First, we explain some of our basic design decisions. Based on that, we will get your project started.

It is important to have some knowledge of `Symfony`_. Sulu is based on Symfony and follows Symfony standards. If you are not familiar with the Symfony framework, you might encounter some difficulties when using Sulu.
